# Kim Korean app

This folder is a Progressive Web App. Host the whole folder on any HTTPS static-web host, then send Naomi the resulting link.

## On Naomi's iPad

1. Open the link in Safari.
2. Tap Share.
3. Choose **Add to Home Screen**.
4. Tap the Kim Korean icon from the Home Screen.

The app works offline after it has been opened once while online.

## Publishing

Upload the complete contents of this folder to a static host, such as Netlify, Cloudflare Pages, GitHub Pages, or a family website. Keep the files together, especially `index.html`, `app.js`, `styles.css`, `flag-theme.css`, `manifest.webmanifest`, `service-worker.js`, and `icon.svg`.
